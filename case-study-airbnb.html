01 / Exploratory analytics

Reading the patterns behind Airbnb listings.

An exploratory Python project focused on cleaning, understanding, and interpreting listing data.

The question.

How can raw Airbnb listing data be prepared and explored so that comparisons are easier to interpret?

The script works with Airbnb_Open_Data.csv, including listing prices, room types, neighbourhoods, cancellation policies, fees, and reviews. It explores how these attributes vary across the available listings.

The approach.

  • Standardise column names, remove duplicate rows, handle missing values, and convert price and service-fee fields to numbers.
  • Compare room types and cancellation policies, calculate average prices by neighbourhood, and inspect price distributions with bar charts and box plots.
  • Explore price–fee relationships and review distributions with pandas, Matplotlib, and seaborn. Export a cleaned CSV for further visual analysis in Tableau.

The contribution.

The combined script connects data preparation, exploratory comparisons, visualisation, and a CSV export in one workflow. Its source makes the imputation choices, filters, and calculations available for inspection.

What the work shows.

The script produces comparison tables, charts, and a cleaned export when run with the source data. These outputs support exploration of listing prices and characteristics. Quantitative findings are not reproduced here because the dataset has not been rerun for this case study.

Before extending the analysis, I would document dataset coverage, test sensitivity to imputation and outlier thresholds, and validate the availability and year fields. Availability is not equivalent to bookings, and review dates alone cannot establish annual listing supply.
